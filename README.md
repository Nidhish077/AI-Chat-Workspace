# Real-Time AI Workspace & Messaging System

 **Live Demo:** (https://fastapi-chat-workspace.onrender.com/)

A high-performance, real-time workspace chat application built using **FastAPI**, **WebSockets**, **Google Gemini AI**, and **Supabase (PostgreSQL)** via **SQLAlchemy Async**. 

The system features real-time bidirectional messaging, presence tracking, automatic message persistence, chat history retrieval, and streaming AI responses triggered via `@ai` mentions using Google's official `google-genai` SDK.


##  Key Features

* **Real-Time Communication:** Bi-directional event broadcasting with WebSockets (`/ws/{channel_id}`).
* **Streaming AI Bot Integration:** Trigger `@ai <prompt>` in any channel to stream AI responses asynchronously using Gemini (`gemini-2.5-flash`).
* **Asynchronous Persistence:** All user messages and AI responses are automatically saved to PostgreSQL using `SQLAlchemy` (Async) and `asyncpg`.
* **Channel History Retrieval:** Fetch complete channel conversation history on demand via `/history/{channel_id}`.
* **Presence Management:** Tracks live online user counts per channel during connection/disconnection events.
* **Production-Ready Deployment:** Configured for cloud deployment on Render with SSL/TLS WebSocket support (`wss://`).


##  Tech Stack

* **Backend Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Python 3.11+)
* **Database:** PostgreSQL via [Supabase](https://supabase.com/)
* **ORM & Driver:** [SQLAlchemy 2.0 (Async)](https://www.sqlalchemy.org/) + [`asyncpg`](https://github.com/MagicStack/asyncpg)
* **AI Provider:** [Google GenAI SDK](https://github.com/googleapis/python-genai) (`google-genai`)
* **Real-Time Layer:** Native WebSockets
* **Deployment Target:** [Render](https://render.com/)

 Getting Started Locally
1. Prerequisites
Python 3.10+

Supabase PostgreSQL connection string (or local PostgreSQL)

Google Gemini API Key

2. Clone Repository
Bash
git clone [https://github.com/your-username/ai-chat-workspace.git](https://github.com/your-username/ai-chat-workspace.git)
cd ai-chat-workspace
3. Create Virtual Environment & Install Dependencies
Bash
python -m venv venv

# On Windows:
venv\Scripts\activate

# On macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
4. Configure Environment Variables
Create a .env file in the root directory:

Code snippet
DATABASE_URL=postgresql+asyncpg://postgres:[YOUR-PASSWORD]@[YOUR-HOST]:6543/postgres
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
5. Run Development Server
Bash
uvicorn main:app --reload
Navigate to http://localhost:8000/ in your browser.

 API & WebSocket Reference
HTTP Endpoints
GET / — Serves the single-page chat client interface.

GET /history/{channel_id} — Returns JSON array of persisted chat history for the specified channel sorted by timestamp.

WebSocket Route
WS /ws/{channel_id} — Connects a client to a channel stream.

Outgoing Message Payload Structure:
JSON
{
  "user": "Alice",
  "text": "@ai What is async IO?"
}
Incoming Event Types (type):
presence — Sent when user joins/leaves. Includes current channel active socket count.

chat — Standard user message broadcast.

ai_start — Indicates Gemini has started generating a streaming response.

ai_chunk — Contains real-time token chunks generated by Gemini.

ai_end — Indicates Gemini finished generating the reply.

error — System error notifications.

 Deployment
This project is optimized for deployment on Render:

Provision a PostgreSQL database on Supabase or Render.

Create a Web Service on Render linked to your GitHub repo.

Configure environment variables in the Render dashboard:

DATABASE_URL=postgresql+asyncpg://postgres:[YOUR-PASSWORD]@[YOUR-HOST]:6543/postgres

GEMINI_API_KEY=your_gemini_api_key_here

GEMINI_MODEL=gemini-2.5-flash

Set Build and Start commands:

Build: pip install --no-cache-dir -r requirements.txt

Start: uvicorn main:app --host 0.0.0.0 --port $PORT
